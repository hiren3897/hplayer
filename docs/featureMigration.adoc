= Advanced features migration doc

- #Backward Button#
- #Forward Button#

Before, the data properties was declared inside the array

[source,json]
----
      {
        "advanced_features": [
          {
            "name": "backward_button",
            "visible": true,
            "data": [{
             "backwardSeconds": 20,
             "color": "yellow"
            }]
          }]
      }
----

Now (LATEST), remove the array and directly declare the properties outside the array as shown below.

[source,json]
----
      {
        "advanced_features": [
          {
            "name": "backward_button",
            "visible": true,
            "data": {
             "backwardSeconds": 20,
             "color": "yellow"
            }
          }]
      }
----
