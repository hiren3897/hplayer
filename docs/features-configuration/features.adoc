= Player Features Configurations

== Common Notes
There are two types of features in the Hexaglobe Player features.

=== Shaka-Player default configuration.
- link:shaka-player-default-features/[how to configure?] In Hexaglobe Player.
- link:https://shaka-player-demo.appspot.com/docs/api/tutorial-ui-customization.html[Take a look at shaka-player default config and feature list!]

=== Hexaglobe player advanced features.
link:hexaglobe-advanced-features[How to configure advanced features?]

Advanced features are developed with the same methodology but with unique functionalities other than shaka player default features.

.Advanced Features Properties
[options="header,footer"]
|=======================
|Property   |Value      |Descriptions
|name       |string     | Name of feature e.g.: small_live_button
|visible    |boolean    |To enable or disable the feature.
|data?      |[ ]        | The data required for this feature
|position?  |number     | Position of the button in the control panel UI.
|color?     |string     |Color of button. Declare it inside the data property (name, RGB, Hex)
|=======================

==== How to configure and enable this feature
Add configuration in player options inside `advanced_features []` array.

===== Fixed Config Snippet

[source,json]
----
{
 "advanced_features": [
   {
     "name": "feature_name",
     "visible": true,
     "data": [{
        "": "",
        "color": ""
      }],
     "position": ""
   }]
}

----
