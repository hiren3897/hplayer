= Poster Feature

* Set the poster attribute on the HTMLVideoElement with the thumbnail URL to have the thumbnail at the start of video.

== Example

[source,javascript]
----
const options = {
  basic: {
    source: "http://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4",
    poster: 'https://alchetron.com/cdn/big-buck-bunny-6636a6ca-0538-4211-a422-2b82ba76d7e-resize-750.jpeg'
  },
}

----
