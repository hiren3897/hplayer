= Switch Channel (Zapping Feature)

- This is a Zapping feature that is used to switch live-streaming channel's. This feature is mainly designed for Live player.

== How to configure and enable this feature

[source,json]
----
  {
    "advanced_features": [
      {
      "name": "switch_channels",
      "visible": true,
      "data": {
        "ui": "list",
        "channels": [
          {
            "name": "Channel one title",
            "source": "https://urltothisvideo.com/manifest",
            "livePlugin": true,
            "drmProtected": true,
            "availableFormats": ["dashwidevine", "hlsfairplay", "dashplayready", "hls"],
            "drm_licence": "https://drmUrltothisvideo.com/csdkslsd",
            "serverCertificate": "https://drmUrltothisvideo.com/csdkslsd",
            "logo": "https://urltoimge.jpg"
          }
        ]
      }
     }]
  }

----

=== Data property
.Zapping Feature data property
[options="header,footer"]
|=======================
|Property |Value     |Description
|ui   | string  | *"list"* view OR *"circle"* view
|channels   | Array   | list of channels with appropriate data.
|=======================

==== Channel properties
.channels array properties
[options="header,footer"]
|=======================
|Property |Value     |Description
|name   | string   | Title of the player.
|source   | string   | A url of the next channel or video. you can also use our plugins in the source configurations.
|livePlugin   | boolean   | To tell player to use live plugin activation
|drmProtected   | boolean   | To tell player that the stream is DRM protected.
|availableFormats   | Array   | An array of available stream formats.
|drm_licence   | string   | DRM url of video.
|serverCertificate   | string   | server certificate if applicable to the video.
|logo   | string   | Logo of channel
|=======================

[NOTE]
You can also configure plugins in the *source* property of the configuration. while using plugin's do not configure the *drm_licence* or *servercertificate* because plugin handles everything for you.

=== Example

[source,javascript]
----
// How to implement the player
const video = document.querySelector('#video')
const videoContainer = document.querySelector('#videoContainer')
const hplayer = new HPlayer(video,videoContainer, {
  basic: {
    source: "http://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4",
  },
  advanced_features: [
      {
      name: "switch_channels",
      visible: true,
      data: {
        ui: "list",
        channels: [
          {
            name: "Channel one title",
            source: "https://urltothisvideo.com/manifest",
            livePlugin: true,
            drmProtected: true,
            availableFormats: ["dashwidevine", "hlsfairplay", "dashplayready", "hls"],
            drm_licence: "https://drmUrltothisvideo.com/csdkslsd",
            serverCertificate: 'https://serverCertificate.com/csdkslsd',
            logo: "https://urltoimge.jpg"
          }
        ]
      }
     }]
})
hplayer.init_();
----

[NOTE]
To have the loaded stream as an item of the switch channel feature, don't forget to add metadata describing the loaded stream in the switch channel configuration. It will allow you to navigate back to the loaded stream while switching other channel streams.
For example, the channel stream loaded while initializing the player is BigBunkBunny Channel, then add the metadata data describing BigBunkBunny Channel in the switch channel configuration at first or any position you prefer.
