= DVR mode Button

- Now, manage your DVR mode timeline with a button click.
- You can activate and dis-activate the DVR mode with your own configured seconds for *NO DVR MODE*.
- You can configure the seconds of the timeline when you dis-activate the DVR timeline.
- You can set the DVR mode to activate or dis-activate at the time of player initialization.

== How to configure DVR mode button.
[source,js]
----
const options = {
  basic: {
    source: 'https://stream_info.mpd',
  },
  advanced_features: [
    {
      name: 'dvr_mode_button',
      visible: true,
      data: {
        noDvrModeTime: 30,
        dvrModeActive: true
      }
    }
  ]
}
----

=== Data property of DVR mode
.DVR mode properties
[options="header,footer"]
|=======================
|Property |Value     |Description
|noDvrModeTime   |Number    | Seconds to be, configured when DVR mode is dis-activated.
|dvrModeActive   |Boolean   | Status of DVR mode to be kept active on start of player or not.
|=======================
