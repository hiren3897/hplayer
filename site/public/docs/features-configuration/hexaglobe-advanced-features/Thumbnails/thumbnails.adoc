= Thumbnails Feature

Display thumbnails to preview video while hovering the timeline
Thumbnails generated by client browser in a hidden video player.

== How to configure and enable this feature

A new thumbnail will be displayed after the user stop moving the mouse for "debounce_delay".
Use for performance and network. Increase the value to reduce network use and less power needed.


[source,javascript]
----
  const options = {
  basic: {
    source: 'https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4',
  },
  advanced_features: [
    {
      name: 'thumbnails',
      visible: true,
      data: [
        {
          // Thumbnails drawing debounce in milliseconds(wait x before drawing new thumbnail)
          debounce_delay: 50,
        }
      ]
    },
  ]
};

----
