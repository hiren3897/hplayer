= Thumbnails Track Feature

== Thumbnails Track

- To preview thumbnail on the timeline scrubbing
- We support thumbnail track preview for both VOD and live.
- Our player is capable of handling both tiled images and single frame/sec layout.
- we recommend to use single frame/sec layout.

[NOTE]
This Feature works only with the Dash and HLS manifest VOD or Live Formats.
All the thumbnail URL should be present in the provided manifest or playlist at the time of setting up the player.

=== Thumbnail Standard Format

link:https://nightly-dot-shaka-player-demo.appspot.com/docs/api/shaka.extern.html#.Thumbnail[shaka.extern.Thumbnail]

=== How to configure and enable this feature

==== VOD
- In VOD, we support thumbnails form source as well as WebVTT.
- To use the source feature set *withWebVtt* to *false*. It will direct the player to use the thumbnail from the manifest (DASH) or playlist (HLS).
- If you are using WebVtt then *withWebVtt* to *true* and provide the required configuration of WebVTT. see *webVttInfo* config below.

[NOTE]
The link:https://www.w3.org/TR/webvtt1/[RFC] implementation of WebVTT thumbnails is very strict.

[source,json]
----
  {
    "advanced_features": [
      {
        "name": "thumbnail_track_vod",
        "visible": true,
        "data": {
          "withWebVtt": true,
            "webVttInfo": {
              "url": "https://path/to/thumbs.vtt",
              "mimeType": "text/vtt",
              "tilesLayout": "1x1"
            }
          }
      }]
  }
----

=== Data property
.Thumbnail Track VOD data property
[options="header,footer"]
|=======================
|Property |Value     |Description | Default
|withWebVtt   |Boolean  | To indicate the player to use WebVTT or Source thumbnails. | false
|webVttInfo   |JSON  | includes WebVTT url, lang, mimeType, tilesLayout | -
|=======================

==== LIVE
- In LIVE, we support thumbnails form source only

[source,json]
----
  {
    "advanced_features": [
      {
        "name": "thumbnail_track_live",
        "visible": true
      }]
  }
----

- We also support thumbnails with DVR of 3 hours. `ONLY FOR LIVE`
** Configure the following settings in the player.
[source,json]
----
{
  "player_configurations": {
    "manifest": {
      "dash": {
        "initialSegmentLimit": 10800 // seconds equivalent to 3 hours.
      }
    }
  }
}
----

[NOTE]
At the time of configuration it is important to configure the following setting for Mac (Safari, Chrome) and iPad (Safari, Chrome) to force player to use MSE to enable the thumbnails from the HLS playlist.

==== HLS Settings
[source, json]
----
{
 "player_configurations": {
    "streaming": {
      "useNativeHlsOnSafari": false
    },
    "manifest": {
      "hls": {
        "useFullSegmentsForStartTime": true
      }
    }
  }
}
----

=== CSS Customization

- To customise your own UI for the thumbnail track you can edit and override the CSS by editing the CSS classed from the following snippet.


==== Snippet VOD
[source,scss]
----
/**
   * Thumbnail Track VOD
   */
.thumbnail-vod-container {
  position: absolute;
  bottom: 75px;
  height: 120px;
  width: 220px;
  pointer-events: none;
  z-index: 10000;
  text-align: center;

  .hexa-vod-thumbnail-image {
    position: relative;
    background-size: cover;
    max-height: 120px;
    max-width: 220px;
  }

  .seekbar-thumb-tooltip {
    color: white;
    font-size: 15px;
    z-index: 100;
    line-height: 1;
    text-shadow: #000000 0 0 4px;
  }

}
----
